# frontend/ — لوحة شروة AI (P3.5)

واجهة عربية RTL **بلا خطوة بناء وبلا حزم npm**: HTML + CSS + JavaScript ES modules، تُقدَّم من الـAPI نفسه على `/console/` (نفس الأصل ⇒ لا CORS). سياسة CSP صارمة (لا سكربت ولا ستايل داخل الصفحة، لا مضيف خارجي)، والرمز يُحفَظ في `sessionStorage` فقط.

## التشغيل محلياً (Windows / PowerShell، من جذر المستودع)

1. قاعدة بيانات وRedis يعملان وقد طُبِّقت عليهما الترحيلات (`python -m app.cli migrate`، وهي تتضمن 0018). متغيّرات الاتصال المعتادة (`CORE_DATABASE_URL` · `CORE_SYSTEM_DATABASE_URL` · `CORE_MIGRATION_DATABASE_URL` · `REDIS_*` · `GATEWAY_*` …) مضبوطة كما في `.env.example`.
2. بذر بيانات تجريبية وتوليد مفاتيح التطوير (يرفض أي قاعدة غير محلية):
   ```powershell
   python scripts/dev_console.py
   ```
   ينشئ أربعة مستأجرين `demo-*` **كلهم مُطفأ التسويق**، ومفتاحاً مؤقتاً تحت `.dev-console/` (خارج git)، وتوكنين: `admin.token` (مدير المنصّة) و`store_a.token` (تاجر).
3. حمّل متغيّرات JWT في نفس نافذة PowerShell التي ستشغّل الـAPI منها ثم شغّل الخادم:
   ```powershell
   . .\.dev-console\env.ps1
   cd core
   python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
   ```
4. افتح `http://127.0.0.1:8000/console/` والصق محتوى `.dev-console/admin.token` (للتاجر: `store_a.token`).

> `env.ps1` يضبط أيضاً `MARKETING_FOOTER_AR` (شرط التفعيل: تذييل صريح) و`CONSOLE_STATIC_DIR` (مسار هذا المجلد). في الإنتاج لا تُشغَّل `dev_console.py` أبداً؛ التوكن يصدر من المنصّة (RS256).

## الشاشات
- **المستأجرون** (مدير المنصّة): جدول كل المستأجرين، المفتاح العام للتسويق (إيقاف فوري/إعادة تشغيل).
- **صفحة مستأجر**: حالة التفعيل، قائمة الفحص التمهيدي، القنوات، معاينة الرسالة (بيانات اصطناعية)، السجلّ الإلحاقي وسجلّ التدقيق، وأزرار تفعيل (بعبارة تأكيد حرفية) / إيقاف / تغيير السقف.
- **المؤشرات**: رسائل يومية (تسويق/مرافِقة/خدمة)، الاشتراكات والإيقافات، حالات السلال ونسبة الاسترجاع؛ للمدير تجميع المنصّة + جدول حسب المتجر، وللتاجر متجره فقط.

## الدخول الموحد من شروه (P4)
تفتح شروه اللوحة بـ`window.open` (بلا `noopener`) على نطاق فرعي لكل متجر، وتنتظر منها `{type:"sharwa-console-ready"}` ثم ترد `{type:"sharwa-console-token", token}` إلى أصل اللوحة وحده. تقرأ اللوحة الأصول المسموح بها من `/console/sso-config.json` (من `CONSOLE_SSO_PLATFORM_ORIGINS`: أصل دقيق أو `https://*.<نطاق-أب>` بعلامة واحدة، والفارغة تعطّل الميزة)، وتقبل توكناً واحداً فقط من `window.opener` بأصل مطابق وبحمولة بشكل JWT، ثم تحفظه في `sessionStorage`. دخول اللصق باقٍ احتياطاً.

## الأمان باختصار
الخادم وحده يقرّر الصلاحيات (الدور المقروء من التوكن في المتصفح للعرض فقط). كل بيانات الـAPI تُرسم بـ`textContent` لا `innerHTML`. لا هاتف ولا نصّ عميل في أي استجابة.
